## 기획

### 누구를 위해

인력사무소 소장과 소규모 시공업체가 같은 Office에서 인력·현장·시공·정산을 운영하고, 작업자와 독립 팀은 Worker에서 배정·작업·문서를 처리한다.

### 왜

회사 운영이 Office와 Works로 나뉘어 현장·참여·사진 연결을 중복 관리하고 있다.
당일 배정·지급 중심의 화면만으로는 월 공수, 주급·월급·고정급과 수당, 자체팀·외부팀의 도급·개별 지급을 함께 운영하기 어렵다.
사용자가 정한 처리 조건대로 계산·문서를 만들고, 근무·계약·청구·지급이 같은 근거로 이어지게 한다.

### 완성되면

- Office에서 회사 운영과 시공관리를 처리하고 Worker와 직접 연결하며, Works의 독립 제품 운영을 종료할 수 있다.
- 인력관리 작업내역에서 이번 달 공수표와 기간별 상세·자료를 보고, 공수/일급 누적 주급·월급과 고정급+수당을 계산해 기존 지급·문서로 연결할 수 있다.
- 작업자 한 명부에서 직원·고정인원 표시와 지급·공제·계약 조건을 각각 정하고, 근로계약을 보내 서명된 최종본과 교부 결과를 보관할 수 있다.
- 자체팀·외부팀을 묶어 운영하고 현장·기간별 도급/개별 지급을 계약할 수 있다. Worker 기존 팀 매출에서 청구서를 주고받고 회사 이동 후에도 계약·미수금 이력을 보존할 수 있다.
- 같은 현장에서 도면·구역·작업·수량·검수·안전과 자재·장비를 관리하고 기존 정산에 근거를 연결할 수 있다.
- Office 앱에서도 현장 사진·자재·장비와 필요한 현장 업무를 처리하고 웹에서 같은 원본을 확인할 수 있다.

### 화면

**인력관리 → 작업자**

별도 직원 명부 없이 기본정보·직원/고정인원 표시 → 지급 조건 → 수당·공제 → 계약·서류를 설정한다.
직원 표시를 하면 근로계약 서식을 바로 제안하며 지급 방식·공제 설정을 자동 변경하지 않는다.
참여 중인 XXX팀은 팀명과 테두리 안에 해당 현장·기간의 팀원들을 펼쳐 보여준다. 머리글에 자체/외부·도급/개별 지급·기간을 표시하고 계약·청구·사진/보고·접근 설정으로 연결한다.

**인력관리 → 작업내역**

상단에는 이번 달 공수표, 하단에는 기간별 작업내역 상세를 보여준다. 월·현장·작업자·팀으로 조회하며 공수표와 상세의 다운로드를 구분한다.
작업자 상세에서는 같은 화면에 해당 작업자 필터를 적용한다.
인력관리의 팀 화면에서 자체팀 생성·편성, 외부팀 연결, 현장 참여·계약·과거 이력을 관리한다.

**작업자 지급 조건 → 기존 정산센터·지급내역**

공수제·일급·시급·기간 고정액과 당일·주·월 지급을 독립적으로 설정한다. 자주 쓰는 패턴을 고른 뒤 수당·공제를 조정한다.
같은 계산 결과에서 기본액·수당·공제·기지급·잔액을 확인하고 문서를 만든다. 기존 지급 원장과 연결하며 주간·월간 화면용 채무를 별도로 만들지 않는다.

**업무센터 → 세무·기관 제출 / 사업장 비치·보관 / 근로자 교부**

근로자 교부의 공수표 카드는 인력관리의 같은 조회·다운로드 화면으로 연결한다.
근로계약은 회사 보관과 근로자 교부 양쪽에서 같은 문서 원본을 본다.
기존 거래처용 청구·노임대장·작업확인서·계산서는 정산/현장 문맥과 전체 문서 검색에서 계속 찾을 수 있다.

**거래처·현장 → 거래처·현장 관리 / 시공관리**

홈에서는 거래처·현장 등록과 기본 계약을 관리한다.
시공관리에서는 선택 현장을 유지하며 작업·공정 / 도면·구역 / 자재·장비 / 검수·요청 / 안전·공지 / 작업기록을 다룬다.
상위 시공관리 메뉴를 당장 추가하지 않고, 향후 동일 기능을 승격할 수 있게 구성한다.

**관제센터 → 선택 현장**

현장·주간·지도는 유지한다. 오른쪽 현장 패널에서 시공관리를 열고 필요한 검수·안전 확인 대기만 확인한다.

**Worker → 본인 작업·팀 참여·개인 문서함·기존 팀 매출**

Office 현장에 참여하고 사진·작업보고·수량을 제출한다.
개인 문서함에서 근로계약을 확인·서명하고 최종 사본을 받는다.
기존 팀 매출에서 Office 현장 계약을 연결하고 청구·정산 서류를 주고받으며 청구액·인정액·지급 통지·수금 확인을 구분한다. 사업자번호가 있으면 서류에 재사용하고 없으면 누락 표시·공란으로 일반 자료를 작성한다.
도급·개별 지급과 무관하게 참여기간에는 허용된 사진·보고 기능을 사용한다. 소장이 현장·기간·팀/팀원별로 접근·입력 범위를 설정한다.
팀의 회사 이동은 종료할 참여를 명시적으로 확인하며, 이전 회사의 자료는 그 회사·참여기간의 기록으로 보존한다.

### 지켜야 할 규칙

- 작업자 표시, 보수 산정, 계산기간·지급 주기, 세금·보험·기타 공제, 팀 참여, Office 관리자 권한은 별개다. 현장직도 직원으로 표시할 수 있다.
- 사용자 선택대로 계산·기록·문서를 만든다. 직원/고정인원·3.3%·보험 조합을 이유로 저장·계산·일반 출력을 막거나 강제 정정·관계 증명·반복 경고를 요구하지 않는다.
- 하나의 선택으로 다른 설정을 자동 변경하지 않는다. 선택한 기준액·산식·비율·금액·출처·효력기간과 결과를 보존한다. 법령 설명은 서식·계산 템플릿의 근거이며 제품의 관계 판정이나 적합성 인증이 아니다.
- 근로계약은 최초 체결·조건 변경·실제 기간 연장 때 버전을 관리한다. 매월 자동 재체결하거나 계속 근무 이력을 초기화하지 않는다.
- 서명 완료와 사본 교부 완료를 구분한다. 서명된 본문은 덮어쓰지 않고 근로자가 지정·동의한 수신 경로에 최종 사본을 전달한다.
- 월 공수표는 실제 근무월 기준이고 지급 원장은 지급월 기준이다. 임금명세서는 임금 지급 때의 별도 문서다.
- 같은 실제 근무를 공수·정산·문서가 공유한다. 이름으로 사람을 합치거나 업무센터용 공수 원장을 따로 만들지 않는다.
- 일정·사진·작업완료·검수·TBM 참석만으로 임금용 공수를 자동 생성하지 않는다. 정산 후 공수는 원본의 정정 절차로 처리한다.
- 공수·일급·시급 누적 주/월 지급과 기간 고정급+추가수당을 이번에 계산·저장·문서까지 구현한다. 금액 직접 입력도 지원하며 외부 확정자료 연결만으로 이 구현을 대신하지 않는다.
- 같은 근무의 주간·월간 조회로 채무를 중복 생성하지 않고 당일 지급·선지급 충당을 같은 지급 원장에 연결한다. 공수에 반영한 연장과 별도 연장수당을 자동 중복 가산하지 않는다.
- 단가·공제 변경은 효력일별로 적용하고 고정급 전액/설정 안분/직접 입력의 근거를 남긴다. 과거 확정·지급은 기존 정정과 차액 처리로 연결한다.
- 자체팀 생성은 Worker 계정·독립 팀 생성이나 관리자 권한 부여가 아니다. 외부팀 원본과 팀원의 권한은 Worker에 유지한다.
- 독립 Worker 팀이 없는 자체팀의 보고·수량·TBM은 Office 원본으로 처리하며 개별 작업자가 본인 배정 권한으로 제출한다.
- 외부팀 연결은 개인 고용·거래처 등록·업체 지급 확정과 다르다. 팀장 수락으로 개인 근로계약 동의를 대신하지 않는다.
- 팀 계약은 현장·기간·작업 범위별로 도급/개별 지급과 총액/공수/수량 등의 산정 기준을 독립 선택한다. 팀 화면 안에서 당사자 입력·기존 거래처 연결·계약 서류를 처리한다.
- 도급팀의 공수·사진·보고는 근거이며 Office 개인 인건비 채무를 자동 추가하지 않는다. 개별 지급은 팀 채무·Worker 팀 매출·비용으로 자동 중복 산입하지 않는다.
- 사업자번호가 없어도 팀 계약·일반 청구자료를 입력·출력한다. 번호가 있으면 재사용하며 일반 문서 송수신과 실제 세금계산서 발급·기관 접수 상태를 구분한다.
- Worker 청구는 기존 Office 받은 청구·PAY에 연결한다. 문서/계약/지급 ID로 중복을 막고 지급 통지와 팀의 수동 수금을 대조한다. 청구·인정·지급·수금은 서로 다른 사실이며 청구 기준 미수금과 상대 인정 기준 잔액을 구분한다.
- 외부팀도 참여기간에는 같은 사진·보고 기능을 쓰며 소장은 자기 현장·기간·대상의 접근을 조정한다. 권한 변경은 과거 원본을 삭제하거나 다른 회사 자료의 권한을 바꾸지 않는다.
- 같은 회사의 여러 현장 작업은 허용하되, 다른 회사 실제 작업의 동시 활성 제한은 1차에서 유지한다. 새 회사 초대 수락으로 이전 작업을 자동 종료하지 않는다.
- 회사 이동·재참여·팀원 변경은 과거 참여기간·작성자·공수·사진·계약·미지급을 바꾸지 않는다. 새 회사에 이전 회사 자료를 자동 공개하지 않는다.
- 사진의 기존 원본 소유자·보존 만료일·공개 동의와 미확정 전송 결과 복구를 보존한다. Works 연결 제거로 회사 사진이 무료 보존 분류로 떨어지지 않게 한다.
- Office 연계 미디어의 첫 저장부터 회사 현장 보존 분류를 적용한다. 이관의 마지막 변경까지 대조하고 전환한 범위의 새 회사 측 쓰기는 Office 한 경로만 허용한다.
- 자재 구매·장비 임차와 사용 기록을 구분한다. 같은 청구·실적이 두 번 비용·지급으로 잡히지 않으며 기존 계약·청구·PAY 기능을 재사용한다.
- 시공수량의 예정·보고·검수 인정과 계약 반영을 구분하고, 단위·산식·버전과 근거를 남긴다.
- 자주 쓰는 서식·위치·공종·산식은 사무소/현장 기본값으로 재사용하되 이미 수락·서명·확정한 기록을 바꾸지 않는다. 자쿠도 같은 조회와 허용된 업무 경로를 사용한다.
- 최종 활성 업무 통신은 Worker ↔ Office다. Works 종료 이후 권한·사진·검수·수량·TBM·공지의 활성 처리에 Works 서버가 필요하지 않아야 한다.
- 문서 용도 분류가 권한을 주지 않는다. 근로자에게는 본인 자료만 교부하고 서명 계약은 일반 작업사진 만료 정책으로 삭제하지 않는다.

### 이번에 안 하는 것

- 도면 자동 인식·BIM 전체 물량 산출, 창고 ERP·재고 평가·감가상각.
- 연차·퇴직금·연말정산까지 포함한 전면 HR 자동화. 기본급·연장수당·주급·월급·설정형 공제는 이번 범위다.
- 여러 회사의 현장을 동시에 작업하게 하는 새 정책과 독립 상위 시공관리 메뉴.
- 모든 산업안전 법정 의무를 자동 충족하는 안전관리 제품.
- 기획 문서 작성만으로 실제 운영 데이터 이관·삭제, Works 운영 중단, 외부 배포를 실행하는 것.

U17-B의 전체 스키마 업그레이드·Spring HTTP 흐름, 로그인한 Office/Worker 연결과 화면·PDF, 정상 자산 환경의 Office production build 및 Worker 전체 mobile 타입/기기 검증은 Codex 검수로 남긴다. 병합·배포·운영 지급 완료를 뜻하지 않으며 아래 41개 확인 문장은 유지한다.

## 확인 항목

- 인력관리 → 작업내역을 열면 이번 달 공수표가 위에, 같은 기간의 상세가 아래에 보인다.

- 업무센터 → 근로자 교부 → 공수표로 들어가면 같은 필터·합계·다운로드 기능이 열린다.
- 같은 작업자가 하루 두 현장에 0.5공수씩 기록되면 전체는 1일·1공수이며 동명이인은 별도다.
- 예정만 있는 날, 기록 없는 날, 확인 대기, 확정 공수가 구분되고 이미 정산한 공수는 단순 덮어쓰기되지 않는다.
- 직원 등록에서 현장직을 선택해 근로조건을 기록할 수 있고 Office 관리자 권한은 자동으로 생기지 않는다.
- 소속 작업자를 고정인원으로 설정해도 고용·소득·보험 구분이 자동 변경되지 않는다.

- 근로계약을 거절·철회하거나 서명 응답을 다시 확인해도 중복 계약이 생기지 않는다.
