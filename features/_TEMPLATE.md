## 기획

### 누구를 위해

누가, 어떤 상황에서 쓰는 기능인지 1~2줄.

### 왜

지금 무엇이 불편하거나 위험한지 2~3줄.

### 완성되면

- 사용자가 새로 할 수 있게 되는 것 (3~6개)

### 화면

메뉴 경로와 탭 구성. 예: 정산센터 → 업체 지급 → 내부 산출 / 정산 검토 / 지급 관리

### 지켜야 할 규칙

- 금액·중복·덮어쓰기 금지 같은 업무 규칙

### 이번에 안 하는 것

- 범위 밖 기능

## 개발 계획

- 첫 단계 제목 | branch: feat/example-step1
- 다른 저장소 단계 | branch: feat/example-step2 | repo: owner/other-repo
- 이미 PR이 있는 단계 | pr: 123
- 브랜치를 아직 정하지 않은 단계

## 확인 항목

- 어떤 화면 → 무엇을 누르면 → 무엇이 보여야 하는지
- 저장 후 새로고침해도 값이 유지되는지
