## 기획

### 누구를 위해

인력사무소·시공회사에서 회사와 현장에 필요한 서류를 챙기는 대표·소장·사무 담당자를 위한 기능이다.
각 업무에서 작성한 문서를 찾고, 실제 준비·제출·확인이 남은 일정을 한곳에서 관리한다.

### 왜

서류가 근로자·정산·현장 화면에 흩어져 있으면 무엇을 준비했고 어떤 기간을 마감하지 않았는지 찾기 어렵다.
사용하지 않는 문서까지 매월 쌓이면 알림을 믿기 어려워진다.
우리 회사와 각 현장에서 관리할 문서를 고르고 실제 업무가 생긴 경우에만 일정을 보여줘야 한다.

### 완성되면

- 회사 유형과 계약관계에 맞는 기본 구성을 받고 문서별 사용 여부를 바꿀 수 있다.
- 현장 등록 시 필요한 서류가 따라오고 고급 옵션에서 그 현장만 변경할 수 있다.
- 문서 일정 관리에서 실제 미마감·마감 완료·관리 중지 업무를 기간과 현장별로 볼 수 있다.
- 작은 A4 양식 미리보기, 공식 이름, 설명, 대상 배지로 서류를 찾아 작업할 수 있다.
- 정산·인력관리·현장 상세와 문서·신고에서 같은 문서와 발행본을 열 수 있다.
- 수동 마감·외부 대행 확인·실제 기관 접수를 구분하고 마감 취소 뒤에도 이력을 확인할 수 있다.

### 화면

기존 업무센터를 **문서·신고**로 바꾸고 하위 메뉴 순서를 고정한다.

| 메뉴 | 역할과 내부 구성 |
| --- | --- |
| 문서 일정 관리 | 기본 홈. 미마감 / 마감 완료 / 관리 중지, 목록 / 캘린더 |
| 사무소 운영·점검 | 법정 장부 / 등록·게시·비치 / 자격·운영 증빙 |
| 근로계약·급여 | 근로계약·인사 / 임금·교부 / 출역·노무청구 |
| 세금·보험 신고 | 소득·원천세 / 사회보험 / 발급·납부 증빙 |
| 공사 계약·현장 안전 | 계약·기성·청구 / 퇴직공제·공사신고 / 안전·작업 증빙 |

PC는 왼쪽 소형 A4 문서 목록과 오른쪽 작업 영역을 사용한다. 큰 양식은 선택해서 연다.
사용 중은 파란 테두리, 사용 안 함은 회색 테두리로 표시하고 현재 선택은 별도 배경으로 구분한다.
평소에는 사용 중인 문서를 먼저 보여주고 `사용 문서 설정`에서 전체 문서와 적용 범위를 고른다.
회사 설정의 `회사 공통 / 새 현장 기본값`과 현장 고급 옵션의 `선택 현장`을 명확히 표시한다.

### 지켜야 할 규칙

- ON은 프로그램에서 관리할지의 선택이다. 법적 의무·고용주·세금 방식·보험 신고주체를 대신 판정하지 않는다.
- 사용 중이고 실제 대상·기간과 일정 발생 조건이 있는 경우만 업무를 만든다. 비치 장부를 켰다고 매월 마감을 만들지 않는다.
- OFF는 해당 문서의 새 준비·집계·알림을 멈추고 기존 미마감은 관리 중지로 분리한다. 기존 완료·원본·확정 급여·청구·지급 금액은 유지한다.
- 다시 ON으로 바꿔도 과거 모든 달을 새로 쌓지 않는다. 지정 기간부터 같은 회차와 이력을 재사용한다.
- 회사의 신규 기본 변경은 기존 현장 예외를 덮어쓰지 않는다. 기존 현장에도 적용하려면 대상과 영향을 별도로 선택한다.
- 제출기한·청구 마감·내부 준비일을 구분한다. 청구일 변경으로 기관 제출기한을 이동시키지 않는다.
- 파일 생성·다운로드·수동 마감은 실제 기관 접수·전자서명·교부·납부를 뜻하지 않는다. 마감 취소와 정정도 이전 기록을 지우지 않는다.
- 정산·인력·현장에서는 같은 문서 ID와 발행 버전을 사용한다. 새로운 계약·급여·지급 원장을 만들지 않는다.
- 민감한 공유 문서는 현재 권한을 검사한다. 이미 교부된 근로계약 사본은 원래 수신자의 보존 권한을 따른다.
- 지원되지 않는 자동작성·신고는 지원 범위를 표시한다. 조회 실패나 정책 미준비를 0건·마감 완료로 표시하지 않는다.

### 이번에 안 하는 것

- 모든 77개 요구사항을 각각 독립 A4 양식과 신규 문서로 만드는 일.
- 모든 기관의 자동 신고·자동 납부·은행 이체와 아직 없는 서명 화면을 한 번에 구현하는 일.
- 계약·세금·보험·급여·지급 계산을 문서 메뉴에 다시 만드는 일.
- 과거 모든 월의 일정 자동 생성, 이미 발행·제출된 원본의 덮어쓰기, 공유 철회된 민감자료의 재노출.
- 문서 기능과 무관한 관제·정산 화면의 전체 재디자인.

## 확인 항목

- 문서·신고 진입 → 문서 일정 관리가 기본 홈이고 네 문서 분류의 이름과 순서가 고정되어 있는지.
- 회사 사용 문서 설정 → 인력사무소 프리셋 선택 → 공사·공제 직접관리 기본 OFF와 실제 대상 조건을 확인할 수 있는지.
- 현장 등록 → 계약관계 선택 → 필요한 문서 요약과 고급 옵션을 볼 수 있는지.
- 현장 고급 옵션 → 모든 문서 OFF로 저장 → 다시 열어도 기본 준비서류가 되살아나지 않는지.
- 새 현장 기본값 변경 → 기존 현장 예외는 유지되고 선택한 기존 현장에만 적용할 수 있는지.
- 문서 목록 → 사용 중·사용 안 함 테두리와 현재 선택 표시가 구분되고 큰 양식을 따로 열 수 있는지.
- 미사용 포함 → OFF 문서를 열어도 자동으로 ON이 되지 않고 이전 발행본을 찾을 수 있는지.
- 문서 일정 관리 → 같은 월별 신고가 중복되지 않고 회사 합산 신고와 현장별 문서가 구분되는지.
- 청구 예정일 변경 → 신고 제출기한이 바뀌지 않고 제출기한·청구 마감·준비 예정일이 구분되는지.
- 비치 장부 ON → 별도 점검이나 확인 주기가 없으면 매월 미마감 일정이 생기지 않는지.
- 미마감 문서 OFF → 관리 중지로 이동하고 완료 문서·정산 금액은 유지되며 새 알림이 멈추는지.
- 관리 중지 문서 ON → 지정 기간부터 같은 회차를 재사용하고 과거 모든 달의 일이 새로 쌓이지 않는지.
- 마감 처리 → 접수증 없이 사용자 확인이나 외부 대행 확인을 남길 수 있고 실제 기관 접수와 구분되는지.
- 마감 취소·정정 → 이전 제출 기록과 발행본·확인자 이력이 남아 있는지.
- 정산·인력관리·현장 상세에서 문서 열기 → 문서·신고와 같은 문서·대상 기간·발행 버전이고 돌아가면 필터가 유지되는지.
- 공유 철회 자료 열기 → 민감 증빙은 차단되고 이미 교부된 근로계약 사본은 원래 수신자 권한으로 조회되는지.
- 외부 안전서류 등록 → 해당 현장과 확인 기한에만 연결되고 실제 자동작성이나 기관 접수 완료로 표시되지 않는지.
- 문서 조회 실패 또는 기능 준비 대기 → 0건·마감 완료와 구분되고 보완 위치나 재시도를 알 수 있는지.
- 운영 홈과 문서 일정 비교 → OFF·마감·관리 중지의 표시 기준이 같고 같은 업무를 중복 알리지 않는지.
- 좁은 화면에서 문서 선택·상세·마감 처리 → 큰 A4 카드에 가려지지 않고 상태를 색상 외 문구로도 구분할 수 있는지.
